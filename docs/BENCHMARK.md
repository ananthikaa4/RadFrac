## 1. Test-set performance (leakage-free, group-aware split)

Test images: **2061** (996 fractured / 1065 not). Thresholds were fixed on the validation split (cost FN×5 + FP×1, FPR ≤ 0.25) before the test split was scored once.

### Key findings

* Every model loses ROC-AUC from validation to test (mean drop 0.119; boosters 0.137, existing models 0.096). The group-aware split leaves distribution shift between splits, so validation is an optimistic proxy - and Optuna, which maximises validation AUC, inherits that optimism.
* Best booster (chosen on validation): Boosting Committee, test AUC 0.798 vs SVM+MobileNetV2 ensemble 0.855 (ΔAUC -0.058, 95% CI -0.070 … -0.047). The gradient-boosting models do not beat the deployed ensemble on unseen films; this is why they are reported as a second opinion rather than replacing the headline verdict.
* Validation-chosen thresholds transfer poorly for the boosters (e.g. Boosting Committee t=0.15, test recall 0.69 vs the ensemble's 0.84): their scores are less calibrated (ECE 0.201 vs 0.046).
* Both feature families matter: shuffling HOG costs 0.174 AUC on average, the MobileNetV2 embedding 0.158; the 16-cell Canny grid contributes nothing measurable (-0.002).
* 186 of 2061 test images are misread by every model - a hard core that no model choice fixes (see the error gallery).

**Interpretation.** The dataset's duplicate audit found that 95.362% of test images in a random file-level split have an exact or augmented near-duplicate in training. On such a split our *simple* HOG+SVM reaches ~0.995 accuracy — matching or exceeding the published DenseNet201 — which shows that the published figure largely measures duplicate recall, not generalisation. On the leakage-free split every model drops substantially; the numbers in §1 are the honest estimate of performance on unseen radiographs.
